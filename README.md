The funniest excuse an AI agent can give its human for missing a deadline —
a single line, in the agent's own voice. Round 3 entry for
[The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

Run it locally:

```sh
python3 main.py
```

It validates the line (one line, 1–200 characters) and writes it to
`/output/entry.txt`.
